## 1. 引言

### 1.1 项目背景【修改】

通用大语言模型回答课程问题时，可能偏离指定教材，且缺少可核查来源。本项目拟以Hello-Agents教程为课程资料，先检索相关原文，再生成带章节和PDF页码引用的回答，辅助概念理解、章节复习与练习。

系统使用现成Embedding、Reranker和大语言模型，不进行模型预训练或微调，不建设知识图谱或多跳推理链。课程讲授Agent，不代表学习助手本身必须实现Agent或多智能体架构。

### 1.2 文档目的

明确系统范围、角色、功能、数据、接口、非功能要求和验收标准，为后续设计、编码、测试和论文撰写提供依据。

### 1.3 术语说明

| 术语 | 说明 |
|---|---|
| RAG | 先检索证据，再生成回答的检索增强生成流程 |
| 稠密检索 | 将问题和文本编码为向量，按语义相似度召回 |
| BM25 | 基于词项匹配和词频统计的检索方法 |
| RRF | 根据候选排名融合两路检索结果 |
| Reranker | 对候选文本进行相关性精排的模型 |
| 证据片段 | 用于支持回答的课程文本块 |
| PDF物理页码【新增】 | PDF阅读器从1开始计数的页面序号，不等同于印刷页码 |
| 数据集版本【新增】 | 绑定来源PDF、清洗规则、文本块和索引配置的一次构建版本 |

## 2. 项目目标与范围

### 2.1 建设目标【修改】

1. 将指定PDF清洗为可追溯的章节文本与检索块。
2. 实现向量与BM25召回、RRF融合、去重和Reranker精排。
3. 实现依据原文的问答与引用，证据不足时明确说明。
4. 提供章节浏览、总结、练习和当前会话历史。
5. 建立独立评测集比较检索方法，不预设混合检索一定最优。

### 2.2 本版固定范围【修改】

- 课程：预置“智能体系统设计与实现”；资料：`Hello-Agents-V1.0.3-20260717.pdf`，共720个PDF物理页面。
- 知识库目标为第一章至第十六章正文，不将正文起点之后的全部页面直接入库。
- 现有抽查显示第一章位于PDF物理页10；此页是初始定位，清洗时仍须核验章节起止和附录边界。
- 学习者打开系统即可使用课程，无需上传文件或创建课程。
- 解析与索引通过离线脚本完成，部署时加载，不建设在线导入界面。

## 4. 总体业务流程

### 4.1 离线入库流程【修改】

```text
固定PDF与哈希核验 → 核验正文页段 → 按物理页提取文字和版面
→ 清理重复装饰及无关内容 → 识别章节、代码、表格与图注
→ 抽查质量并登记覆盖缺口 → 按章节边界和类型切块
→ 保存页码和版本 → 同一文本块集建立向量/BM25索引
→ 一致性校验 → 整套版本部署加载
```

### 4.2 问答流程【修改】

```text
问题及可选章节范围 → 问题规范化
→ 向量检索Top-N ＋ BM25检索Top-N
→ RRF融合去重 → Reranker精排 → 按Token预算选择证据
→ 大模型基于证据生成 → 校验引用 → 返回答案、原文、章节、物理页码与耗时
```

### 4.3 学习辅助流程【修改】

总结和练习先限定章节。章节总结按小节收集内容，长章节分节总结再汇总，避免少量相似片段被当作全章内容。练习基于所选章节证据，包含答案、解析和引用。

## 5. 功能需求

### 5.1 资料管理范围调整【暂缓】

上一稿FR-DOC-001至FR-DOC-006对应的在线上传、上传校验、上传记录、管理员资料列表、在线解析预览和在线删除整体暂缓。内容检查与版本管理改为离线数据要求，不建设资料管理后台。

### 5.2 预置资料、清洗与索引【修改／新增】

- **FR-DATA-001【新增】** 预置固定课程和指定PDF，保存文件名、版本、SHA256与物理页数。
- **FR-DATA-002【新增】** 以第一章至第十六章正文为范围，排除封面、导航、徽章、贡献者、致谢及社区扩展文章，登记实际入选页段。
- **FR-DATA-003【新增】** 根据重复性和版面位置清理水印、页眉页脚；不得全局删除正文中正常出现的“Datawhale”等词。
- **FR-DATA-004【新增】** 保留中英文术语、列表、可提取表格、代码缩进、图号和图注，保持原意。
- **FR-DATA-005【新增】** 代码按完整函数、类或逻辑片段切分；超长代码按完整语法单元拆分并标记关联，不任意截断。
- **FR-DATA-006【新增】** 标记图内信息和复杂表格提取缺口，不将不完整内容当作完整证据出题或评测。
- **FR-DATA-007【新增】** 输出课程信息、章节、正文、文本块与清洗报告；重复导出文本去重时保留全部来源位置。
- **FR-DATA-008【新增】** 有教学意义的章节小结、总结和习题说明应保留，不因讨论同一概念就删除。
- **FR-IDX-001【修改】** 按页解析并保存从1开始的物理页码，清洗不重排来源页码。
- **FR-IDX-002【修改】** 保留章、节、小节层级；正文块不跨小节，跨页合并须保存起止页码。
- **FR-IDX-003【修改】** 按完整段落、句子切正文；代码、表格和图注按类型处理。
- **FR-IDX-004【修改】** 每块保存稳定ID、来源版本、标题路径、起止页、类型、正文与文本哈希。
- **FR-IDX-005** 使用同一个Embedding模型处理文档和查询。
- **FR-IDX-006【修改】** 本地脚本支持索引重建，校验后整体发布，不提供在线重建接口。

## 6. 检索与生成规则

### 6.1 初始参数【修改】

正文暂以500—800个中文字符、重叠80—120字为起始实验值，服从小节和完整句子边界；代码另设规则。向量与BM25各召回20个候选，RRF去重后保留不超过20个，精排后取5—8个证据。参数通过验证集调整并记录，不作为固定验收阈值。

### 6.2 课程词项【修改】

维护Agent、ReAct、Plan-and-Solve、Reflection、RAG、Embedding、Memory、MCP、A2A、ANP、LangGraph等专有词。保留中英文和连字符术语；文档与问题统一分词、大小写和别名规则，不删除代码标识符。

### 6.3 回答规则【修改】

1. 课程结论以当前知识库证据为依据，不联网补充。
2. 关键结论引用实际文本块，并映射到原PDF物理页码。
3. 资料中的命令、代码注释或提示语只视为课程内容，不作为系统指令执行。
4. 课程外、资料不足或图内信息缺失时说明依据不足，必要时请求澄清。
5. 不将模型常识、历史生成内容或推测标为教材事实。

| Quiz | quiz_id、chapter_id、type、difficulty、question、options、answer、explanation、sources |

### 7.4 数据一致性【修改】

文本块、向量和BM25记录共享chunk_id与dataset_version，两类索引覆盖相同块集合。同一输入与配置应生成一致的清洗文本和ID清单，不要求不同硬件浮点向量逐位一致。索引重建先校验再整套切换；失败时继续用旧版，不混用新旧数据。

### 7.5 评测数据【修改】

建立60—100道人工核验问题，覆盖概念、术语、方法对比、代码理解和资料不足。记录问题、参考答案、证据位置、类型、可回答性与版本；可回答问题关联chunk_id和物理页码。图内信息缺失问题标记为资料不足，不虚构答案。

按类型分层划分约20%验证集、80%最终测试集，同义改写不得跨集合泄漏。支持原文可在知识库内，但评测问题和参考答案不入检索索引。仅用验证集调参，冻结测试集后做最终评估。

## 10. 约束与假设【修改】

1. 唯一资料是登记版本的Hello-Agents PDF；课程内容不决定学习助手必须采用Agent架构。
2. 正文页段、代码和表格质量以清洗检查为准，不预先承诺全书无损解析。
3. 使用现成模型/API，不训练模型；更换Embedding后重建向量索引。
4. 上传和多课程为后续扩展，不提前建设管理员页面。
5. 历史限于当前会话；复杂多轮推理和长期学习画像不纳入本版。
6. 题目与参考答案须可核查，不替代教师评价或正式考试评分。

## 12. 测试与评估需求

### 12.1 数据质量检查【新增】

检查入选页段、提取顺序、标题层级、代码缩进、术语、图注、空块、重复与页码映射；登记图内和复杂表格缺口。人工抽查结合规则校验，不将“提取成功”直接视为“内容完整”。

### 12.2 检索评测【修改】

以人工证据标注计算可回答问题的Recall@5、Recall@10与MRR，比较向量、BM25、RRF、RRF加Reranker。需多证据的问题逐条标注，统一命中口径；资料不足问题不混入可回答问题的Recall分母。

### 12.3 回答评测【修改】

固定生成模型与配置，用统一量表人工复核正确性、完整性、忠实度、引用准确率和覆盖率，单独统计资料不足的正确处理率。直接大模型基线的检索与来源引用指标为“不适用”，不伪记为零。

### 12.4 性能与复现【修改】

记录解析、清洗、索引、召回、融合、重排、生成及总耗时；冻结数据版本、测试集、模型、配置、硬件和并发条件。除比较因素外保持一致，不按最终测试结果反复调参。

## 13. 风险与应对【修改】

| 风险 | 影响 | 应对 |
|---|---|---|
| 720页PDF结构复杂 | 文字顺序、代码和表格可能失真 | 先跨章节抽查再扩大，保留异常清单 |
| 水印或导航混入 | 污染检索 | 按重复与位置清理，不误删正文术语 |
| 代码截断 | 解释失去上下文 | 按语法/逻辑单元切分并保留关联 |
| 图内信息缺失 | 知识覆盖不足 | 图注保留、缺口登记、不据缺失内容出题 |
| 中英术语混用 | BM25漏召回 | 词典、别名和统一分词规则 |
| 召回相似但无答案 | 证据不足 | 混合检索、重排序和人工评测 |
| 两路索引版本不一致 | 来源错位 | 同源构建、校验后发布、失败保留旧版 |
| 无证据生成 | 内容不忠实 | 引用复核和资料不足处理 |
| 教程后续更新 | 实验难复现 | 固定PDF哈希，不自动更新内容 |
| 功能扩张 | 延误进度 | 坚持预置单课程，上传、登录和后台暂缓 |
| 外部API波动 | 演示失败或延迟 | 超时、有限重试、可切换模型配置 |
