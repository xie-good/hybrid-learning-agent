# 基于混合检索增强生成的课程学习助手：论文清单与阅读建议

检索日期：2026-10-27。使用 paper-search CLI 查询 Crossref、OpenAlex、arXiv，并使用期刊、会议及作者预印本原始页面补充核对。以下为 12 篇题录/摘要级筛选，非全文精读或穷尽性系统综述。

## 一、优先阅读

建议顺序：1 EduChatQA → 2 CHSR-RRF → 3 CourseAssist → 9 M3-Embedding → 10 RRF → 12 RAGAs。排序依据是与“课程学习助手 + 稀疏/稠密混合检索”的贴近程度及实现参考价值，而非引用量排名。

## 二、论文清单

### 课程学习助手与教育问答

#### [1] EduChatQA: curriculum-aware hybrid retrieval and teacher-aligned prompting for textbook-grounded educational QA

- 作者：Jingqiang Guan；Jialu Li；Kun Hou；Jingyuan Li
- 年份与出处：2026，Complex & Intelligent Systems；期刊论文。
- DOI：10.1007/s40747-026-02342-z
- 原始来源：[EduChatQA: curriculum-aware hybrid retrieval and teacher-aligned prompting for textbook-grounded educational QA](https://link.springer.com/article/10.1007/s40747-026-02342-z)
- 相关性：最直接相关。将 BM25 与稠密向量信号融合，并结合教材知识图谱、师生角色提示、多轮话题控制和无答案判断。
- 可用于毕设：相关工作；混合检索设计；课程溯源与多轮问答。
- 混合检索口径：BM25 + 稠密向量；另含知识图谱绑定

#### [2] CHSR-RRF: A curriculum-gated hybrid retrieval framework with reciprocal rank fusion and leakage-aware benchmarking for educational RAG

- 作者：Terence Ateya；Zavier Ndum Ndum；Jicheng Fu；Kelly Tendongkeng
- 年份与出处：2026，arXiv:2609.02913；预印本；本次未核实正式发表版本。
- DOI：10.48550/arXiv.2609.02913
- 原始来源：[CHSR-RRF: A curriculum-gated hybrid retrieval framework with reciprocal rank fusion and leakage-aware benchmarking for educational RAG](https://arxiv.org/abs/2609.02913)
- 相关性：最直接相关。先按课程元数据限制候选范围，再进行稀疏/稠密检索、RRF 融合与重排；针对跨学科、跨年级的课程错配建立评测。
- 可用于毕设：课程/章节过滤；混合召回与融合；课程范围正确性评测。
- 混合检索口径：稀疏 + 稠密 + RRF

#### [3] CourseAssist: Pedagogically Appropriate AI Tutor for Computer Science Education

- 作者：Ty Feng；Sa Liu；Dipak Ghosal
- 年份与出处：2024，SIGCSE Virtual 2024；会议论文；所链接 arXiv 为作者版本。
- DOI：10.1145/3649409.3691094
- 原始来源：[CourseAssist: Pedagogically Appropriate AI Tutor for Computer Science Education](https://arxiv.org/abs/2407.10246)
- 相关性：面向计算机课程的 RAG 学习助教，结合用户意图分类和问题分解，使回答贴合课程材料及教学目标。
- 可用于毕设：需求分析；系统功能；教学适宜性与用户体验评价。
- 混合检索口径：本文摘要未将 BM25 + 稠密混合检索列为核心贡献

#### [4] Retrieval-Augmented Tutoring for Algorithm Tracing and Problem-Solving in AI Education

- 作者：Mragisha Jain；Tirth Bhatt；Griffin Pitts；Aum Pandya；Peter Brusilovsky；Narges Norouzi；Arto Hellas；Juho Leinonen；Bita Akram
- 年份与出处：2026，BEA 2026, Association for Computational Linguistics；会议论文。
- DOI：10.18653/v1/2026.bea-1.57
- 原始来源：[Retrieval-Augmented Tutoring for Algorithm Tracing and Problem-Solving in AI Education](https://aclanthology.org/2026.bea-1.57/)
- 相关性：KITE 基于课程材料提供算法推演、提示和渐进式引导，同时结合 RAGAs、专家评价和模拟学生评价。
- 可用于毕设：从直接答题转向启发式辅导；教学质量评价。
- 混合检索口径：多模态课程 RAG；不等同于已确认 BM25 + 稠密混合检索

## 三、技术路线边界

应在论文中明确定义“混合检索”。若项目实际使用 BM25 + 稠密向量，则应主要讨论稀疏/稠密双路召回、结果融合及重排。第 6 篇的 Hybrid RAG 是 Vector RAG + Graph RAG，可作为扩展研究现状，但不应与前者混写。第 9 篇模型输出的学习式稀疏表示也不等于 BM25。

## 四、据文献归纳的毕设实验建议

以下是面向本题目的设计建议，不是这些论文已经共同验证的结论。

- 数据：使用一门真实课程的教材、课件及教学材料；为样本保留课程、章节、页码或文件出处。
- 对照：纯 LLM、BM25-RAG、向量 RAG、混合检索 RAG；如果实现重排，再加入“混合检索 + 重排”。
- 问题：分别覆盖术语精确匹配、同义改写、跨章节综合、课程外问题与多轮追问。
- 指标：检索使用 Recall@k、MRR 或 nDCG；回答使用正确性、证据忠实性、引用正确性；另做人工教学适宜性评价并记录延迟。
- 若研究动态调权，需对比固定权重和 RRF，保持语料、生成模型、提示模板和上下文预算一致。
- 课程范围过滤应单独消融，避免把课程隔离效果误归因于融合算法。
