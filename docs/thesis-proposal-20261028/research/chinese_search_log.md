## 一、学术索引命令

```powershell
paper-search tool search_crossref '检索增强生成 教育' --max-results 5
paper-search tool get_crossref_paper_by_doi '10.11959/j.issn.2096-0271.2025062'
```

第一条命令返回5条相关性较弱的记录，未直接纳入。第二条命令正常退出，标准输出为 `{}`；因此该论文不以Crossref缺失记录判假，也不以CLI成功退出代替书目核验，转由出版方文章PDF核实。第二条命令的原始输出保存在本目录 `chinese_education_crossref.json` 和 `chinese_education_crossref.stderr.txt`。
